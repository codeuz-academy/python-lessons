[Python](https://www.python.org) - umumiy maqsadli interpretatsiya qilinadigan dasturlash tili. Python har kuni uchraydigan dasturiy ta'minot yaratishda o'qilishi oson, ifodali va amaliy bo'lishi uchun yaratilgan. Uning sodda sintaksisi Pythonni boshlovchilar uchun qulay qiladi, shu bilan birga yirik ishlab chiqarish tizimlari uchun ham yetarlicha kuchli.

Til ilk bor 1991 yilda [Guido van Rossum](https://en.wikipedia.org/wiki/Guido_van_Rossum) tomonidan chiqarilgan va hozirda [Python Software Foundation](https://www.python.org/psf/) tomonidan qo'llab-quvvatlanadi.

Python keng qo'llaniladi:

- **Avtomatlashtirish va skriptlar**: takrorlanuvchi vazifalar va tizim boshqaruvini avtomatlashtirish
- **Veb dasturlash**: Django, Flask va FastAPI kabi freymvorklar (frameworklar)
- **Ma'lumotlar ilmi va mashinaviy o'qitish**: Pandas, NumPy, scikit-learn, TensorFlow va PyTorch kabi kutubxonalar
- **Ilmiy hisoblash**: SciPy, Matplotlib va Jupyter notebook'lar
- **DevOps va backend servislar**: cloud vositalari, CI/CD pipeline'lar, infratuzilmani avtomatlashtirish
- **IoT va o'rnatilgan qurilmalar**: Raspberry Pi, MicroPython

Python barcha asosiy operatsion tizimlarda (Windows, macOS, Linux) ishlaydi va ko'plab Linux tizimlarida oldindan o'rnatilgan bo'ladi.

Ushbu darslar to'plami **Python 3.13** tili va standart kutubxonasi uchun yozilgan.

```python
print("Python is simple and powerful")
```

Python toza sintaksis va muhim indentatsiyadan foydalanadi. Har bir qatordan keyin nuqta-vergul qo'yish shart emas.
