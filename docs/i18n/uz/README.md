# [Belajarpython](https://www.belajarpython.com/) &middot; [![GitHub license](https://img.shields.io/badge/license-MIT-blue.svg)](https://github.com/codeuzhub/python-lessons/blob/main/LICENSE) [![PRs Welcome](https://img.shields.io/badge/PRs-welcome-brightgreen.svg)](https://github.com/codeuzhub/python-lessons/blob/main/.github/CONTRIBUTING.md)

Belajarpython - Pythonni o'rganish uchun hamkorlik platformasi.

- **Darslarni o'qing:** Pythonni boshidan o'rganishni boshlang. Boshlovchilar uchun tayyorlangan darslar sizga tezroq rivojlanishga yordam beradi.
- **Maqolalarni o'qing:** Turli mavzulardagi eng so'nggi va eng ommabop Python maqolalarini o'rganing. Mazmun hamjamiyat tomonidan hamjamiyat uchun yaratiladi.
- **Savol bering:** Duch kelgan har qanday Python savolini bering. Hamjamiyat a'zolari yechim topishda yordam berishga tayyor.

## Hissa qo'shish

Belajarpython - dasturchilar tomonidan dasturchilar uchun yaratilgan open-source veb-sayt.
